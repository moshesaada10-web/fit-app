# האימונים של משה — PWA

אפליקציית מעקב אימונים בעברית (RTL), מותאמת לטלפון. Vite + React + TypeScript, בנייה סטטית.
הנתונים נשמרים ב־localStorage במכשיר בלבד: בלי חשבון, בלי שרת. עובדת אופליין ואפשר להתקין למסך הבית.

מקור התוכנית: `/workspace/outputs/moshe-training-plan-v2.html` (תרגילי A/B/C, סטים×חזרות, שבועות היכרות, כללי התקדמות, שבוע קל 6 ו־12, אירובי Zone 2, כללי עצירה ודגלים אדומים).
האיורים הם איורים סכמטיים שנחתכו מהחוברת הקודמת (עמודים 8–23). לחלופות ללא איור יש כרטיס טקסט בלבד.

## הרצה

```bash
npm install
npm run build           # בדיקת טיפוסים + בנייה ל-dist/
npx vite preview --host # http://<כתובת-המכונה>:4173
npm test                # בדיקות יחידה (רוטציה, שבוע קל, התקדמות, כאב, מגמת משקל)
npm run dev             # פיתוח
```

להתקנה בטלפון: לפתוח את הכתובת בדפדפן ולבחור "הוסף למסך הבית". ה־service worker דורש HTTPS או localhost,
כך שבגישה ב־`http://<IP>:4173` מהטלפון ההתקנה/אופליין לא יפעלו; להעלות את `dist/` לכל אחסון סטטי עם HTTPS (או `tailscale serve` וכד').

npx vite preview --port 4173 &

## מבנה

- `src/data/plan.ts` — התוכנית, תרגילים, חלופות, טקסטי בטיחות
- `src/data/muscles.ts` — קבוצת שרירים לכל תרגיל וחלופה (הראשונה היא העיקרית ורק היא נספרת)
- `src/logic/` — רוטציה ושבוע קל (`rotation.ts`), התקדמות (`progression.ts`), כלל כאב (`pain.ts`), משקל (`body.ts`), בניית אימון (`workout.ts`),
  סיכום שבועי והצעה (`weekly.ts`), סדר תרגילים וסט נוסף (`adjust.ts`), דפוסים ארוכי טווח (`patterns.ts`)
- `src/store.ts` — מצב ב־localStorage, ייצוא/ייבוא/איפוס
- `src/screens/` — היום, אימון, סיום, יומן, אירובי, התקדמות, בטיחות, הגדרות, סיכום שבועי (`Review.tsx`, `#/review/<יום ראשון>`)

## כללים עיקריים

- האימון הבא = הבא ב־A→B→C אחרי האחרון שהושלם (לפי תאריך), בלי קשר לימי השבוע.
- 3 אימוני כוח = שבוע בתוכנית; שבוע קל אחרי 15 ואחרי 33 אימונים (כל 18 = 6 שבועות): כ־40% פחות סטים, כ־10% פחות משקל.
- התקדמות: קצה עליון של טווח החזרות בכל הסטים ב־2 אימונים באותו משקל → מדרגת המשקל הקטנה. אחרי שבוע קל חוזרים למשקל שלפניו.
- כאב ≥4 או החמרה בבוקר → סט פחות וקל יותר; פעמיים ברציפות באותו תרגיל → השהיה ופנייה לפיזיותרפיסט.
- בלי אישור פיזיו (הגדרה), לחיצת רגליים וכפיפת ברך מוחלפות אוטומטית בחלופה.
- הנחיות כלליות בלבד, לא ייעוץ רפואי.

## סיכום שבועי והתאמה

- שבוע = ראשון עד שבת. מיום שישי (ובכל יום אחרי שהשבוע נגמר, אם עוד לא טופל) מופיע בהיום כרטיס "סיכום שבועי".
- הסיכום: אימוני כוח מתוך 3, אירובי מתוך 2, סטים שבוצעו מול המתוכנן לכל קבוצת שרירים, דילוגים, כאב והערות, ושורת סיכום ("פספסת רגליים וחזה, גב עבד יפה").
  אימון שלא בוצע נספר כמתוכנן (0 סטים); אימון שנרשם בדיעבד בלי פירוט נספר לפי התוכנית.
- "בפיגור" = פחות מ־75% מהסטים; "יפה" = 90% ומעלה.
- הצעה לשבוע הבא (באישור אחד, "אשר שינויים"): עד 2 הקבוצות שהכי בפיגור עוברות לתחילת כל אימון, עם תג "הוקדם" שמסביר למה.
  ליבה וידיים לא מוקדמות לעולם (עייפות ליבה לפני תרגילים מורכבים מסוכנת לגב). ההתאמה פעילה עד שבת של השבוע הבא ואז חוזרת לבד.
- סט נוסף (רשות, אפשר לבטל בהצעה): לכל היותר 2 לקבוצה ו־3 בשבוע, רק אם מספר הסטים של השבוע מתחת למספר המלא בתוכנית,
  לא בשבוע קל, לא בשבועות ההיכרות, לא לרגליים בלי אישור פיזיו, לא לתרגיל שמסומן בכלל הכאב ולא כשהכאב הכללי פעיל. נבדק שוב בכל בניית אימון.
- הרוטציה לא משתנה: אם היו רק 2 אימונים, השבוע הבא מתחיל מהשלישי כמו קודם.
- דפוסים (אחרי 3 שבועות נתונים, חלון של 4 שבועות): אחוז השלמה לכל תרגיל ואיזון קבוצות. הצעות: החלפה קבועה לחלופה לתרגיל שמדלגים עליו
  ב־50%+ מהפעמים (לא לתרגיל שמסומן בכאב), או "להשאיר X ראשון" כשקבוצה בפיגור ב־3 מתוך 4 שבועות. רק באישור; ביטול בהגדרות; הצעה שנדחתה לא חוזרת 4 שבועות.
- הכול נשמר בגיבוי JSON. גיבוי ישן נטען עם ברירות מחדל (אותו `version: 1`, שדות נוספים בלבד, כך שגם גרסה ישנה שעדיין פתוחה לא מוחקת אותם).

## הכנה לסקי (בלוק 12 שבועות)

- הגדרה "הכנה לסקי" (ברירת מחדל: פעיל) + תאריך טיול (ברירת מחדל 7.1.2027). בהיום: ספירה לאחור ושבוע בבלוק. לוגיקה: `src/logic/ski.ts`, תרגילים: `src/data/ski.ts`.
- סיום של כ־10 דק׳ בסוף כל אימון (3 תרגילים): A הליכה צידית עם גומייה, פלאנק צד, שיווי משקל על רגל אחת; B גשר על רגל אחת, פאלוף, עלייה איטית למדרגה נמוכה; C חרק מת, ישיבה רדודה על קיר, שיווי משקל.
  עלייה למדרגה וישיבה על קיר רק עם אישור פיזיו (`legsCleared`); בלי אישור: צדפה / גשר עם החזקה, עם תג "דורש אישור פיזיותרפיסט".
- שבועות 1–4 למידה ו־2 סטים, 5–8 יותר סטים וזמן, 9–12 החזקות ארוכות; שיווי משקל: מבט קדימה → משטח רך → סיבובי ראש. שבוע קל של התוכנית או 7 הימים האחרונים לפני הטיול: כ־40% פחות סטים (לא מצטבר).
- תמיד אחרי התרגילים העיקריים (ההתאמה השבועית לא מזיזה אותם), עם תיוג קבוצות שרירים לסיכום השבועי.
- אירובי: 35–40 דק׳ משבוע 5, 40–45 משבוע 9, 20–25 קל בשבוע האחרון. משבוע 7 אינטרוולים עדינים באופניים (4×3 דק׳ בינוני), רק בלי כאב ולא בשבוע קל.
- גיבוי ישן נטען עם ברירות המחדל של הסקי.

## עדכון באפליקציה מותקנת

`registerType: 'autoUpdate'` עם `skipWaiting` ו־`clientsClaim` (חייבים להגדיר במפורש כי `injectRegister: false`).
גרסה חדשה נכנסת מיד והדף נטען מחדש; האפליקציה בודקת עדכון כשחוזרים אליה וכל שעה. הנתונים והאימון הפתוח ב־localStorage נשמרים.
